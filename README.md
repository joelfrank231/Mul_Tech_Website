# Mul-Tech Static Website (GitHub Pages)
Responsive multi-page HTML/CSS/JavaScript website. No Python server needed.

## Files
- index.html — Home
- about.html — About
- services.html — Services
- products.html — Products
- contact.html — Contact inquiry form
- assets/style.css and assets/script.js
- assets/images/*.jpg — JPEG promotional banners containing English text

## Before publishing
1. Replace phone, email and location placeholders in contact.html.
2. Replace REPLACE_WITH_YOUR_EMAIL in the FormSubmit form action to enable submissions (external provider). GitHub Pages itself does not process forms.

## GitHub Pages deployment
1. Create a repository and upload the contents of this folder.
2. Open repository Settings → Pages.
3. Select deploy from branch, choose main and root (/), then save.
4. Wait for the published URL to appear in Pages settings.
